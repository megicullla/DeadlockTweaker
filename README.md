изменяет значения FOV в файлах игры, что позволяет ставить поле зрения выше чем предлагает игра. Так как происходят постоянные обновления, файлы обновляются и FOV сбрасывается, дабы не лазить каждый раз в файлы, был разработан данный софт

# EN

A tool for changing the FOV in the game Deadlock. This program modifies FOV values in the game files, allowing you to set a field of view higher than what the game normally allows. Since updates are released frequently, the files get refreshed and the FOV resets, this software was created so you don’t have to manually edit the files every time.

<br />

> [!WARNING]
> This software is not a cheat, miner, or virus. You will not be banned.

## How to use

1. [Download](https://github.com/megicullla/DeadlockTweaker/releases) and run DLTweaker.exe
2. Select the desired action (enter 1–2)

<br />

> [!CAUTION]
> An issue may occur when locating the game folder. In that case, the program will prompt you to enter the correct path to the game.
By default, the path looks like:
"C:\Program Files (x86)\Steam\steamapps\common\Deadlock"
